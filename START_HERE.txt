SQL Clinic — Instalación rápida (Windows o Linux)
=================================================
1. Abre una terminal en esta carpeta.
2. Ejecuta: python -m venv .venv
3. Activa: .venv\Scripts\Activate.ps1 (Windows) o source .venv/bin/activate (Linux/Mac)
4. Ejecuta: pip install -r requirements.txt
5. Ejecuta: python -m uvicorn app.main:app --reload --port 8010
6. Visita: http://127.0.0.1:8010

La primera carga realiza mediciones reales del motor SQLite de la demo.
Las mediciones cambian con la carga del equipo. PostgreSQL / Docker son opcionales.
Lee README.md para la metodología y laboratorio avanzado.
